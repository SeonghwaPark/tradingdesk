## 두 축

### 축 B — 학습 레이어 🎓 (이 프로젝트의 차별점)
"설명 붙이기"가 아니라 **fisher님의 이해도를 기억하고 성장시키는** 구조.
1. **멘토 에이전트** — 매 세션 개념 1개 풀이 + 소크라테스식 퀴즈 (`.claude/agents/mentor.md`) ✅
2. **학습 프로필** — 배운 것/헷갈리는 것/커리큘럼을 기억하는 durable 파일 (`workspace/_learning/profile.md`) ✅
3. **개념 스포트라이트** — 매번 딱 1개 개념을 깊이 → 반복하면 전 범위 마스터 ✅ (멘토 로직)
4. **복기 루프** — 페이퍼 손익(성적표)이 나오면 "왜 맞/틀렸나" 복기 → 실전 학습 (Phase 2 연동 예정)
5. **온디맨드 학습** — `/learn <개념>`으로 아무때나 질문 ✅

## 로드맵 (탑 쌓기: 각 단계가 다음의 재료)
- **[완료] 학습 골격**: 멘토 + 학습 프로필 + /learn
- **Phase 1 — 신뢰도** 🛡️: 웹 숫자를 yfinance 실제값과 교차검증·경고, (선택) DART 공시 연결
  - → 밸류에이션 분석가(축 A #5)의 재료가 됨
- **Phase 2 — 성적표** 📊: 진입가 기록 + `/desk review` 페이퍼 손익 → 복기 루프(축 B #4)의 재료
  - → 리스크 매니저(축 A #7)의 재료가 됨
- **Phase 3 — 팀 확장** 👥: 뉴스·매크로·밸류에이션·리스크 분석가 추가 → 원본 9개 완성
  - 새 에이전트가 붙을 때마다 **멘토가 그 개념을 자동으로 가르침** → 팀이 클수록 학습량↑

## 설계 원칙
- 학습 레이어를 **먼저** 세웠기에, 이후 어떤 분석가를 붙여도 멘토가 그 지식을 fisher님께 전달한다.
- 모든 것은 읽을 수 있는 마크다운 파일에 남는다(에이전트 동작·학습 이력 모두 추적 가능).
- 페이퍼 트레이딩·학습 목적. 실거래·자금이동 없음.
