# 📖 기술적 분석 입문 (주린이용)

TradingDesk의 `technical.md`를 읽을 때 옆에 두고 보는 용어·체크포인트 사전.
어려운 말은 최대한 풀어 썼고, 실제 우리 리포트에서 나온 값으로 예를 든다.

> ⚠️ 기술적 분석은 "확률/타점"을 보는 도구지 미래를 맞히는 마법이 아니다. 지표는 대부분 **후행적**(이미 일어난 가격을 계산)이다. 펀더멘털(회사 실적·업황)과 **같이** 봐야 한다.

---

## 1. 이동평균선 (이평선, Moving Average)
**뜻**: 최근 N일 종가의 평균을 이은 선. 가격의 "평균 흐름"을 부드럽게 보여준다.
- **20일선(SMA20)** = 최근 20거래일 평균 → **단기** 흐름
- **60일선(SMA60)** = 최근 60거래일 평균 → **중기** 흐름

**왜 보나**: 지금 가격이 평균보다 비싼지/싼지, 추세가 위인지 아래인지 감을 준다.

**체크포인트**
- 현재가가 이평선 **위** = 그 기간 평균보다 비쌈(강세 경향)
- 현재가가 이평선 **아래** = 평균보다 쌈(약세 or 조정)
- 📌 예) 삼성전자: 현재가가 20일선 **아래(-12.3%)**, 60일선 **위(+3.1%)** → *단기엔 밀렸지만 중기 추세는 아직 살아있다* = "눌림목 초입"

## 2. 정배열 / 역배열
**뜻**: 이평선들의 줄 세우기.
- **정배열** = 단기선(20일)이 장기선(60일) **위** → 상승 추세 신호
- **역배열** = 단기선이 장기선 **아래** → 하락 추세 신호

**체크포인트**: 20일선 > 60일선이면 정배열. 📌 삼성전자는 아직 정배열(20일 328,775 > 60일 279,785)이나 단기선 기울기가 꺾이는 중.

## 3. 골든크로스 / 데드크로스
**뜻**: 두 선이 교차하는 순간.
- **골든크로스** = 단기선이 장기선을 **위로** 뚫음 → 상승 전환 기대
- **데드크로스** = 단기선이 장기선을 **아래로** 뚫음 → 하락 전환 경계
- (우리 리포트의 MACD 항목에서도 "골든/데드"라는 말을 쓴다 → 5번 참고)

## 4. RSI (상대강도지수, 0~100)
**뜻**: 최근 상승분과 하락분을 비교해 "너무 올랐나/너무 빠졌나"를 0~100으로 표시.
- **70 이상 = 과매수** (단기 과열, 조정 가능성 ↑)
- **30 이하 = 과매도** (단기 낙폭 과대, 반등 가능성 ↑)
- **30~70 = 중립**

**체크포인트**: 과매도(30↓)에서 반등하면 매수 타이밍 참고. 📌 삼성전자 RSI 43·NVDA 43.3 = **둘 다 중립** → "아직 바닥 확인은 안 됨, 더 빠질 여지도 있음".

## 5. MACD (이동평균수렴확산)
**뜻**: 단기·장기 이평선의 차이로 **모멘텀(힘의 방향)**을 보는 지표. "MACD선"과 "신호선(signal)" 두 개를 비교한다.
- MACD선이 신호선 **위** = **골든**(상승 힘 우위)
- MACD선이 신호선 **아래** = **데드**(하락 힘 우위)

**체크포인트**: 📌 삼성전자·NVDA 모두 **데드** → 단기 하방 힘이 아직 우세. "반등보다 눌림 경계" 국면.

## 6. 지지선 / 저항선
- **지지선**: 가격이 잘 안 깨지고 튕겨 올라오던 아래쪽 가격대(살 사람이 몰리는 곳). 이평선이 지지선 역할을 자주 한다.
- **저항선**: 위로 잘 못 뚫던 가격대(팔 사람이 몰리는 곳).

**체크포인트**: 📌 삼성전자의 단기 지지선 후보 = **60일선(약 280,000원)**. 여기서 버티면 반등 기대, **종가로 깨면** 매수 근거 약화 → 관망.

## 7. 52주 고점/저점
**뜻**: 최근 1년 최고가·최저가.
- **고점 대비 -%**: 고점에서 얼마나 빠졌나(조정 깊이). 📌 삼성 -20.4%, NVDA -16.1%.
- **저점 대비 +%**: 저점에서 얼마나 올랐나.
- ⚠️ 가끔 데이터 오류로 저점이 비정상적으로 낮게 잡힘(삼성 예시의 +383%) → 이상치는 무시.

## 8. 눌림목 / 분할매수
- **눌림목**: 상승 추세 중 잠깐 쉬어가며 가격이 내리는 구간. 추세가 살아있다면 매수 기회가 되기도 한다.
- **분할매수**: 한 번에 다 사지 않고 여러 번 나눠 사는 것. 바닥을 정확히 못 맞히니 **위험을 쪼개는** 방법.

**체크포인트**: 📌 삼성전자 결론이 "60일선 지지 확인하며 **분할** 매수"인 이유 = 추세는 살아있으나(눌림목) RSI·MACD가 아직 반등 신호는 아니라서 한 번에 안 담는 것.

## 9. 거래량
**뜻**: 얼마나 많이 사고팔렸나(차트 아래 막대). 가격 움직임에 **힘이 실렸는지** 확인용.
**체크포인트**: 상승에 거래량 실리면 신뢰도 ↑, 하락에 거래량 폭증하면 투매 경계.

## ✅ technical.md 읽는 순서 (요약 체크리스트)
1. **추세**: 정배열? 현재가가 20일·60일선 위/아래? (지금 방향)
2. **모멘텀**: RSI 중립/과열/과매도? MACD 골든/데드? (지금 힘)
3. **위치**: 52주 고점 대비 얼마나 조정? (싼 편인지 감)
4. **타점**: 지지선(주로 이평선) 어디? 분할매수 vs 관망?
5. **항상**: 이건 가격 얘기일 뿐 → 실적·업황(research/analysis)과 합쳐 최종 판단.

> 처음엔 1·2번(추세·모멘텀)만 챙겨 봐도 충분하다. 리포트를 반복해 보다 보면 자연스럽게 익는다.
